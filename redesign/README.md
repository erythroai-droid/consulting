# ПСБ Консалтинг — redesign

Современный широкоэкранный редизайн главной страницы по макету
[Figma «ПСБ Консалтинг»](https://www.figma.com/design/yO5CWfFTomrcIq3fjxSPA5/?node-id=207-0) (фрейм `Desktop_1`, 256:2).
Собран по тому же принципу и на том же стеке, что и La Scala (`C:\dev\LaScala\redesign`):
Next.js + React 19 + GSAP ScrollTrigger + Lenis (нативный скролл, без ScrollSmoother), i18n RU/EN, шрифты через `@fontsource`.

Первая сборка лежит в корне репозитория (`C:\dev\consalting`) и не тронута — для сравнения.

```bash
npm install
npm run dev     # http://localhost:3300
npm run build && npm start
```

## Блоки макета → редизайн

| Макет | Редизайн |
|---|---|
| Слайдер с жёлтой колонкой, логотипом, адресом, телефоном, меню и стрелками | Первый экран на всю высоту: ч/б фото меняются под сплошной жёлтой колонкой, логотип стоит на ней, текст на колонке тёмный (копия текста, обрезанная по колонке), слайды сменяются шторкой, прогресс автопрокрутки + кнопка паузы, адрес/телефон/меню в шапке и нижней панели. Экран остаётся на месте, следующий блок наезжает на него |
| Плашка из 5 услуг (активная — жёлтая) | «Что мы делаем»: 5 высоких карточек во всю ширину, наведённая заливается золотом |
| Преимущество покупки готовых фирм | Фото с параллаксом + вторая карточка с золотой тенью, чек-лист со щитами, цитата; бегущая строка услуг по скроллу |
| Каталог готовых фирм (чёрная шапка, жёлтая полоса «Купить», «Скачать каталог», «Перейти в каталог») | Семантичная таблица; клик по строке раскрывает золотую полосу «Купить» → диалог заявки; на узком экране таблица складывается в карточки (container query) |
| Отзывы (фото в точках, «КЛИЕНТЫ», кавычки, точки) | Тёмный закреплённый экран, гигантское «КЛИЕНТЫ» едет по скроллу, автопрокрутка с паузой |
| Партнёры со стрелками | Бегущая строка логотипов: останавливается при наведении, есть кнопка паузы; при «уменьшении движения» — неподвижная лента с прокруткой |
| «Остались вопросы? Напишите нам» + фото девушки + футер | Один блок в конце страницы: форма как в макете (поля слева, «Вопрос» справа), телефон и адрес, фото, меню, «ПСБ КОНСАЛТИНГ» во всю ширину собирается по буквам, копирайт |

Общий мотив макета — золотой квадрат за первыми буквами заголовка — сохранён во всех секциях и «вырастает» при появлении.

## На телефонах и при «уменьшении движения»

До 900px, на сенсорных экранах и при `prefers-reduced-motion` — статичная страница: без закреплений и плавного скролла.
При «уменьшении движения» автопрокрутка слайдера и отзывов стартует на паузе.

## Перед запуском в прод

- Формы демонстрационные: `LeadForm` ничего не отправляет (см. `onSubmit`).
- Адрес взят из макета и выглядит как заглушка (`40 Baria Street 133/2, New York City, US`, в макете с опечаткой «Sreet») — заменить в `lib/site.ts`.
- Каталог — демо-строки: в макете одна строка повторена 8 раз.
- Отзывы — заглушки: в макете латинский «Lorem ipsum»; фото клиентов 2 и 3 — из первой сборки.
- «Скачать каталог» и «Весь каталог» открывают заявку на каталог: файла и страницы каталога в макете нет.
- Домен сайта — `https://psb.erythro.ai` (metadata, og:image); переопределяется переменной `NEXT_PUBLIC_SITE_URL`.
